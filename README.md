# 骂社火 · 专题站

河南省三门峡市灵宝市阳平镇东常村、西常村的省级非遗「东西常骂社火」专题站。
纯静态站点，无构建步骤、无外部依赖，双击 `index.html` 即可打开，也可整包拷到 U 盘/服务器。

---

## 一、打开与部署

- **本地看**：双击 `index.html`（Chrome / Edge / Safari 均可）。
- **投屏演示**：浏览器全屏（F11），建议 1920×1080；页面在 1280、1440、1920 下都按 1200px 容器居中。
- **上线**：把整个文件夹传到任意静态托管（Nginx、GitHub Pages、对象存储）即可，无需后端。

## 三之二、实践页的照片和视频

这一页放的是**自己的东西**，和影像页分开：

- `assets/img/field/live-*.jpg` —— 传承人提供的历年活动照片，8 张，按内容命名（羊皮袄 / 芯子 / 探马 / 牵牛 / 彩门 / 旗 / 花脸 / 杆上孩子）。加图就在 `practice.html` 的 `.gridgal` 里复制一个 `<figure>`。
- `assets/img/field/team-*.jpg` —— 团队自摄：考察现场、试穿、道具、校园那一场。
- `assets/video/loop.mp4` —— 页头 8 秒无声循环，960×544；`loop-sm.mp4` 是手机用的 540 宽版本；`poster.jpg` 是首帧。
- 视频换法：把新的 mp4 覆盖 `loop.mp4` 与 `loop-sm.mp4`（后者压小），再截一张首帧存成 `poster.jpg`，尺寸 960×544 即可。手机端会自动选 `loop-sm.mp4`；开了「减弱动效」的系统只显示海报、不播视频。

改文字时注意两处别写错：**我们没看过现场演出**（活动停办多年），看到的是场地、道具和传承人手机里的存照。

## 五、展陈模式（现场投屏用）

任意页面右上角点「展陈模式」，进入全屏轮播：

- 6.5 秒自动换一张，底部红线是进度；
- `←` `→` 手动切换，`空格` 暂停，`ESC` 退出；
- 鼠标移到右上控制区会暂停，方便讲解。

图片顺序与解说词都在 `assets/js/exhibit-data.js`：

```js
{ src: 'assets/img/parade.jpg', cap: '拜请', sub: '一句话解说……' }
```

增删条目即可，`cap` 是大标题，`sub` 是小字说明。

## 六、设计说明（为什么这么做）

- **色**：宣纸 `#f2e9db` + 墨 `#14100d` + 朱砂 `#b23a2b`。三种颜色对应「纸、墨、印」，不用第四种；红只给需要被看见的地方（标题字、编号、引文、进度条）。
- **字**：标题用楷体，正文用宋体。楷体近手写，配得上「村口唱词」的语气；宋体保证长文可读。
- **结构**：全站用「壹贰叁」编号 + 英文小字标签，像地方志的目录；正文每段控制在 40 字以内一行，为投屏距离留余地。
- **叙事**：首页按「一年只活六天」的时间线走，先给时间和场面，再给规矩和学理——先让人觉得好看，再让人发现它有内容。
- **克制**：不用渐变按钮、不用大圆角、不用阴影堆叠。这个题材的分寸感比炫技重要。

## 七、还可以做（按优先级）

1. 换完实拍图后，把 `gallery.html` 的「说明」改成田野来源，并加摄影署名。

3. 若有采访录音，可在 `ritual.html` 的「语言标本」旁加一个 `<audio>`，比文字更有说服力。
4. 想要二维码：把网址生成二维码图片放进页脚第三列即可。
